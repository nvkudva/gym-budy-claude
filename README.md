# 🏋️ Gym Buddy AI

A premium AI-powered gym exercise tracker with an Apple-style glass morphism UI. Get a personalized weekly workout plan generated by Google Gemini, track every set and rep, and chat with your AI coach anytime.

## ✨ Features

### 🎯 Personalized Onboarding
- Collects your name, age, height, weight, and fitness goal
- Choose from 6 goals: Muscle Gain, Weight Loss, Endurance, General Fitness, Strength, Running
- Set your experience level and available equipment
- AI generates a custom 7-day weekly plan on completion

### 📅 Weekly Plan View
- Color-coded day cards with expandable exercise lists
- Today's workout highlighted with a quick-start button
- Animated weekly completion progress ring
- One-tap AI plan regeneration

### 💪 Workout Tracker
- Day-by-day exercise sessions
- Per-set weight and reps logging
- Auto 60-second rest timer after each completed set
- Exercises and days auto-complete as you progress

### 📊 Progress Dashboard
- Weekly volume, completion rate, and session stats
- 7-day training volume bar chart
- Personal records leaderboard (gold / silver / bronze)
- BMI and profile summary

### 🤖 AI Coach Chatbot
- Powered by Google Gemini 2.5 Flash
- Answers questions on exercise form, nutrition, diet, and recovery
- **Modifies your workout plan live** — just ask ("replace bench press with push-ups", "add more cardio", etc.)
- Full conversation history preserved across sessions

## 🚀 Getting Started

### 1. Clone the repo

```bash
git clone https://github.com/nvkudva/gym-budy-claude.git
cd gym-budy-claude
```

### 2. Install dependencies

```bash
npm install
```

### 3. Add your Gemini API key

Create a `.env.local` file in the project root:

```bash
cp .env.local.example .env.local
```

Then edit `.env.local` and add your key:

```
VITE_GEMINI_API_KEY=your-gemini-api-key-here
```

> Get a free API key at [Google AI Studio](https://aistudio.google.com/app/apikey)

### 4. Start the dev server

```bash
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.

## 🎨 UI Design

The app uses an **Apple-style glass morphism** design system built entirely with Tailwind CSS:

- **Background** — deep navy/purple radial gradient
- **Cards** — `backdrop-blur-xl` frosted glass with subtle borders
- **Colors** — each goal and day gets a unique color gradient
- **Animations** — fade-in, slide-up, progress rings, bounce loaders
- **Typography** — SF Pro / system font stack

## 🔒 Privacy

All your workout data (profile, plan, progress, chat history) is stored **locally in your browser** using `localStorage`. Nothing is sent to any server except the AI prompts to Google's Gemini API.
